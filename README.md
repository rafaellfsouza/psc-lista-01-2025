## 📖 Sobre

Lista inicial da disciplina **PSC — Programação de Soluções Computacionais**, cobrindo os fundamentos: saída de dados, declaração de variáveis tipadas e leitura de entrada do usuário.

Os exercícios foram resolvidos primeiro em **Portugol** (pseudocódigo executável do Portugol Studio) e depois portados para **Java**, o que ajuda a fixar a diferença entre a lógica e a sintaxe de cada linguagem.

## 📚 Exercícios

| Arquivo | Linguagem | O que faz |
|:---|:---:|:---|
| `Olá Mundo.por` | Portugol | Programa mínimo — imprime `Olá Mundo` |
| `OlaMundo (1).java` | Java | Mesmo programa em Java, com `public static void main` |
| `Escreva seu nome.por` | Portugol | Declara uma variável `cadeia`, pede o nome ao usuário e o imprime |
| `Nome, idade, altura.por` | Portugol | Trabalha três tipos de variáveis — `cadeia`, `inteiro` e `real` — lendo e exibindo nome, idade e altura |

## 🧠 Conceitos aplicados

- Estrutura básica de um programa Portugol: `programa { funcao inicio() { ... } }`
- Tipos primitivos: `cadeia`, `inteiro`, `real`
- Entrada e saída: `leia()` / `escreva()`
- Ponto de entrada do Java: `public static void main(String[] args)`
- `System.out.println` como equivalente do `escreva`

## ▶️ Como executar

**Java:**
```bash
git clone https://github.com/rafaellfsouza/psc-lista-01-2025.git
cd psc-lista-01-2025

javac "OlaMundo (1).java"
java OlaMundo
```

**Portugol:** abra os arquivos `.por` no [Portugol Studio](http://lite.acad.univali.br/portugol/) e execute com <kbd>F5</kbd>.
